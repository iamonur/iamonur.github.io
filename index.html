Featured Auction Assistant

Auction Assistant

It's a desktop companion app (Electron + React + TypeScript) for WoW players who craft and trade on the Auction House — it pulls prices from Battle.net's API or TSM's free feed into per-game-version local databases, then surfaces that data as profitability tools: what to craft for profit, where to gather or farm for a target item, which mobs and zones are worth the kill, and the cheapest path to level a profession. A companion in-game Lua addon extends that data onto item/mob/zone tooltips inside WoW itself and can scan the live Auction House to feed fresher prices back — synced one-way through WoW's SavedVariables files, since addons can't otherwise talk to outside processes. It spans three WoW products (Retail, Classic Era, Classic Progression) each with fully isolated data, and is GPL-3.0-licensed because its bundled mob/loot/zone reference data is derived from open-source emulator world databases.

TypeScript Lua Electron React
